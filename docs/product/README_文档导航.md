# HOPPA 产品文档包

## 文件清单

- `HOPPA_产品需求文档_PRD_v1.0.docx`：主 PRD，含原型截图、产品定位、用户问题、MVP 范围、功能需求、数据模型、指标、风险边界和验收标准。
- `HOPPA_PRD_v1.0.md`：PRD Markdown 版本，便于放入代码仓库供代码 Agent 阅读。
- `HOPPA_交互与页面规格_v1.0.docx`：页面级交互与状态说明，含关键演示脚本。
- `HOPPA_交互与页面规格_v1.0.md`：交互规格 Markdown 版本。
- `HOPPA_VibeCoding开发任务书.md`：可交给代码 Agent 的开发总提示词。
- `HOPPA_作品集呈现与面试复盘指南.md`：作品集叙事、简历模板、面试问题与用户验证建议。
- `HOPPA_功能验收与数据埋点.xlsx`：需求清单、事件埋点、测试用例和指标口径。
- `assets/`：从用户提供的原型包中选取的关键页面截图。

## 建议使用顺序

1.  先阅读 PRD，确认 P0 / P1 / P2 范围。
2.  将文档包或至少两个 Markdown 规格文件放入代码仓库的 `docs/` 目录。
3.  将 `HOPPA_VibeCoding开发任务书.md` 发给代码 Agent，要求先检查仓库并输出实施计划。
4.  分阶段开发，不要一次性生成所有功能。
5.  每阶段对照 Excel 的验收清单测试。
6.  完成后按作品集指南补充真实测试结果和迭代过程。

## 重要边界

这是用于求职作品集的 MVP 规格，不是正式上线的生产级社交产品。真实定位、真实报警、身份核验、支付、实时通讯和外部地图服务均不在第一版范围内。任何未执行的测试或未验证的用户假设都必须如实标注。
